# Steps That Changed Dance

This folder is a complete, static version of the Hyde Park School of Dance Hispanic dance history quiz. It can be hosted at no charge with GitHub Pages and does not require a server, database, build command, or paid hosting plan.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository. A suggested name is `hpsd-hispanic-dance-quiz`.
2. Unzip the downloaded package on your computer.
3. In the new repository, choose **Add file → Upload files**.
4. Drag these items into the upload area together: `index.html`, `app.js`, `assets`, `.nojekyll`, and this `README.md` file.
5. Select **Commit changes**.
6. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/(root)`. Select **Save**.
7. GitHub will display the public web address when deployment is complete. Open it on a phone before creating the bulletin-board QR code.

## Important notes

- Keep every file and folder name unchanged, especially the `assets/people` folder.
- The leaderboard is stored only in the visitor's browser. It is not shared across phones or computers, which avoids collecting children's names or personal information.
- Use initials only on the leaderboard. The quiz includes an inappropriate-word filter, but an adult should still test the public version before sharing it.
- The image-credit information is included inside the quiz.

## Updating later

Upload the revised files using **Add file → Upload files**, allow them to replace files with the same names, and commit the changes. GitHub Pages will republish automatically.
